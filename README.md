# 은하와 우주 실험실

중학교 3학년 과학 「Ⅶ-2 은하와 우주」 수업에서 학생들이 태블릿으로 쓰는 시뮬레이션과 퀴즈입니다. 설치 없이 브라우저에서 열립니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 |
| `milkyway.html` | 우리은하 탐험기 (1차시) |
| `nebula.html` | 성운 시뮬레이터 (3차시) |
| `quiz.html` | 천체 감별 함께 퀴즈 (3차시) |
| `expand.html` | 우주 팽창 시뮬레이터 (4·5차시) |
| `credits.html` | 사진 출처와 안내 |

- 학생 정보를 모으지 않으며, 외부 스크립트·글꼴·분석 도구를 쓰지 않습니다.
- 사진의 저작자와 라이선스는 `credits.html`에 있습니다.
- 시뮬레이션 속 수치는 개념을 보여 주기 위한 단순 모형 값입니다.
